## Strategic Rationale

**Phase 1:** Target solo developers who work in Claude Code and prefer text-based interfaces via MCP. Use Phase 1 to validate that the web app visualization is useful (it will be needed for Phase 2 teams anyway). Get deeply engaged users, measure retention/churn.

**Phase 2:** When Phase 1 hits 5k+ engaged users, pivot to B2B teams. Web app is already built and tested. Add team collaboration features, monetize per-user ($10-20/user/month).

**Why this works:** Solo devs validate the product and prove market fit. Easy upsell to teams. VC pitch is strong (proof of product-market fit without paid acquisition).
