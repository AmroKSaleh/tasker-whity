Next stage of a UX design pass on Tasker. We ran a "blind triangulation" review of the PROJECT BOARD screen — two independent AI reviewers (Claude in Claude Code, and Gemini) each did a Steve Krug "Don't Make Me Think" review without seeing the other's, then findings were compared: agreements = high-confidence, divergences = closer look, factual disputes settled against the actual code/CSS. This task = apply that same lens to the modes we HAVEN'T reviewed yet: the Blueprint dependency graph, and the individual task-level / flow-contract views.

## Locked framework to carry forward (agreed output of the board review)
1. Two-halves hierarchy — AMPLIFY signal + SUPPRESS noise. On the board this meant: kill the redundant "MEDIUM" priority word/dot that's stamped on ~80% of cards (only non-default priorities should announce themselves), AND lift the section-count contrast. Measured: the x/y counts render in --color-mute-2 (#9A9896) on column bg #F5F3ED = ~2.6:1, which FAILS WCAG AA (needs 4.5:1). Fix = bump to --color-mute (#6B6867, ~5:1).
2. Progressive disclosure — for multiple simultaneous alerts, rank by FLOW TOPOLOGY (earliest upstream choke point rendered full; clearing it can cascade-unblock downstream), downstream failures go slimline (colored bar + icon only), and the tail collapses to a "+N more blocked" count. Never render every alert at full volume (alarm fatigue / shattered layout).
3. Semantic quarantine — RED is reserved STRICTLY for systemic outages (API key revoked, DB down). An AI hitting a contract gate is the system working as designed (a handoff), NOT a failure — never color it red or use a ⛔ stop-glyph.
4. Ambient governance — the AI's operating boundaries (Context / KB / IS) stay PERSISTENTLY visible in the header (they reinforce the user's mental model that the AI is governed); never bury them behind a gear. Fix = group + label them as a distinct "AI governance" cluster, separated from view-toggles (Blueprint/Focus).
5. Signal color for "AI blocked / needs human review" = INDIGO (#4B57D8) — LOCKED. Decided by a pre-attentive A/B test on the real palette: because the board is a warm/orange-saturated field, a "louder orange" blocked state camouflages into the ambient orange (Resume button, seed tags, in-flight bar). Indigo wins by color-TEMPERATURE break — a cool interruption the eye finds before reading, without triggering crisis-red panic. A/B mockup artifact: https://claude.ai/code/artifact/221f1d5d-b93c-491e-ab74-758e5c594fc0

## Open items from the mockup (nobody verified these yet)
- Color-blindness: confirm warm-orange vs cool-indigo holds up for deuteranopia/protanopia (likely safe, but check).
- Dark theme: retune the indigo signal against dark ground (--color-paper #16151B); #4B57D8 may need lightening.
- The ◆ diamond glyph and the "AI" flag chip in the mockup are placeholders — pick real iconography.
- White text on the deep-orange/indigo chips: verify contrast (indigo passes; re-check any orange usage).
