When creating a reusable flow block (suggested name: **Flow Template**), the user can base it on an existing flow rather than starting from scratch. The block editor opens with the existing flow's tasks pre-loaded, and the user can add, remove, or reorder tasks/steps freely.

The tasks inside a Flow Template act as templates — not literal tasks. The content and context within each task (title, detail, etc.) serve as a scaffold that gets populated from the context of whatever the template is being applied to. For example, applying a "New Branch Onboarding" template to a specific branch would auto-fill each task's context with that branch's details.

This makes Flow Templates a context-aware scaffold, not a static copy-paste.
