This may seem like a counter to everything that we did until this point. But, it isn't, as in many cases (like now for me personally) the user's limits run out. This means that the user will mot be able to user Tasker that well. I think that we should increase the independence of Tasker in case the user doesn't want to use MCP with it. This is a long discussion that we gotta make. It should be kept in mind tho that I don't mean to decrease the importance of the MCP connection, I just want Tasker to have some type of independence outside of it. Maybe each task will have a tab (which is hidden by default) that gives exact steps of the task at hand so that the user is able to accomplish the task himself, independent of the AI platform he uses.
