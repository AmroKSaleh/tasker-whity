The back arrow ("←") in the section focus view is too small — hard to see and a small click target. Make it larger / easier to hit.

Location: V2/app/src/components/board/ProjectBoard.jsx, in the project header block. It renders when focusedSectionId is set:
  <button onClick={() => setFocusedSectionId(null)} className="text-mute hover:text-ink mr-2">←</button>
(~line 601). It sits next to the focused section's <h1> title.

Fix direction: bump the glyph size and padding (and/or swap the bare "←" for a lucide ArrowLeft icon at a readable size, ~16–18px) so it reads as a proper button and is comfortable to click. Keep it consistent with the editorial button styling used elsewhere in the header.

Shipped 2026-07-02 as part of the TDE-352 design pass (commit 6a49122): the tiny "←" text arrow in the section-focus header is now a proper bordered "‹ Back" button (btn btn-sm, ChevronLeft icon + label, tooltip "Back to board (Esc)"). Deployed to live.
