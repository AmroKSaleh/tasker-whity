A simple, read-only (or minimal-interaction) mobile view scoped to developers who already have Tasker's MCP configured. Not targeting a general mobile audience — this serves the existing user on their phone.

Core use cases:
- Check what tasks are open in a project/section
- See a task's full detail (context, milestones, status)
- Mark a task done or update its status without opening a laptop
- Quick-glance on flow progress

What it is NOT:
- A full-featured mobile task manager
- A replacement for the desktop web app
- A path to a general/non-developer audience

Scope decision (from TDE-151 discussion, 2026-06-16): the "magic prompt" general-audience angle was retired — MCP solves the root problem. This task is the only mobile angle worth pursuing at Phase 1, because it serves the same user (developer with MCP) rather than a different one.
