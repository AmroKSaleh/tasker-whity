From Linear: project updates are structured posts with a mandatory health enum (On track / At risk / Off track) + rich text; Linear AUTO-ATTACHES the delta since the last update — target-date changes, lead changes, milestone progress, overall progress when it moved >2%. Latest update pins to the project overview; a "Write with Agent" button drafts the update from changes + linked discussion, human edits and publishes. The delta engine is the sleeper feature — the research's strongest single adaptation.

Build: post_project_update MCP tool (health: on_track|at_risk|off_track, body); the SERVER computes and attaches the delta since the last update (tasks completed, sections progressed, dates slipped, new/blocked items); latest update pinned to the Front Page lead card with health color; history on the project. Agent-drafted flow: agent reads the computed delta, drafts, human publishes.

Extends Day Summary (TDE-160) from day-scoped to project-scoped, and gives cross-session recaps durable anchors — human-shared state narrated for humans. Related: TDE-251 (AI-as-dashboard evaluation).
