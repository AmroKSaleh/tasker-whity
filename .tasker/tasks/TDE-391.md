From Linear: agent-session Plans carry per-step status pending/inProgress/completed/canceled so the UI shows where the agent IS, not just what's done; highlighted checklist text converts directly into sub-issues; team toggles auto-close a parent when all children complete; an outgrown sub-issue converts upward.

Build on Tasker milestones (currently binary done/not-done): (a) add in_progress and canceled milestone states — the inspector then shows the agent's current position inside a task; (b) convert checklist text in a task detail into real milestones (one click / one MCP call — also enforces the existing milestones-not-note-checklists rule mechanically); (c) optional per-task auto-complete when all milestones are done — BLOCKED when the task has review enabled (the gate always wins); (d) promote an outgrown milestone to a full task.

Small, cheap, and directly serves inspectability: "where is the agent right now" at a glance.
