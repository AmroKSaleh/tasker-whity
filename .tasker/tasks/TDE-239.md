Decision (TDE-237): flow artifacts should live in GitHub, not in Tasker storage. Extend the existing GitHub integration (github_connect etc.) with two new MCP tools: one to commit a file to a specified path in the connected repo, one to read it back. A flow can store its artifacts at a conventional path (e.g. .tasker/artifacts/{flow-short-id}/). store_artifact should optionally trigger a commit when a repo is connected. This is a natural fit with the repo-native pivot direction.
