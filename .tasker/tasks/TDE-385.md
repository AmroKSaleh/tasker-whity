From Linear: team-level auto-archive moves closed issues to a per-team Archives page after a set period — archived items stay searchable and one-click restorable; deleted issues sit in "Recently deleted" for 30 days before permanent removal; a separate auto-close setting handles stale open issues.

Build: (a) auto-archive tasks done for > N months — hidden from default views, still searchable, restorable, NEVER silently deleted; (b) a recently-deleted holding state with a 30-day restore window for tasks/projects (today deletion is final — scary in a system whose whole promise is durability); (c) stale flags — a task sitting in_progress with no MCP activity for N days gets flagged and surfaced on Today/Front Page as suggest-only. Explicitly NOT auto-close: agents legitimately park long-running work; the human decides.

Wedge rationale: durable state rots without hygiene, and archive-don't-delete is the trust posture "durable, human-shared state" implies. Boards also get faster as done-task volume moves out of default queries.
