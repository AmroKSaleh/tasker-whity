Root cause: MCP server only read params.arguments in tools/call. The Claude Code VS Code extension sends tool arguments as params.input instead of params.arguments (different from the desktop app). This caused args.project_id to be undefined on the extension, making every project-scoped tool fail with "Project undefined not found".

Fix: index.ts line 4404 now accepts both:
  const { name, arguments: toolArgs, input: toolInput } = params
  runTool(sb, userId, name, toolArgs ?? toolInput ?? {})

Deployed to Supabase, committed cc9230d.
