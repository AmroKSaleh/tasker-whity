Successor to TDE-873, which shipped everything else and is closed. This exists because the defect is VISIBLE IN PRODUCTION RIGHT NOW: the project-update metrics panel renders the Blocked figure struck through, with a caption naming the task to fix it. That caption should point at live work, not a completed task.

THE DEFECT. get_project_delta computes blocked_items with `.eq('status', 'blocked')`. A task's status is only ever pending / in_progress / done — there is no 'blocked' status, no migration defines one, and nothing in the codebase writes it. The number has therefore been structurally incapable of being anything but 0 since the feature shipped. It printed a confident "0 Blocked", which reads as "nothing is stuck" — an assertion the data cannot support.

Owner decision 2026-08-06: leave it in place and STRIKE IT THROUGH rather than delete it, so the defect stays visible until fixed properly. That is the current live state — see DeltaMetrics in app/src/components/board/FrontPage.jsx and blocked_metric in computeProjectDelta.

THE FIX IS REPOINTING, NOT INVENTING. Tasker has a real blocked concept: flow dependencies. unmetSourcesDeep(sb, task.input) already computes whether a task's upstream inputs are unfinished, and it is what hard-blocks starting or completing such a task elsewhere in the MCP. A genuinely blocked task is one that is not done and has unmet upstream sources.

WATCH OUT — the cheap version is wrong. Computing this per task across a whole project means a JSONB reverse-lookup over every I/O edge, which is why list_tasks disables cursor pagination when its `blocking` filter is used. Check the cost before shipping it on a call that runs every time someone opens a project's front page.

ALSO WORTH SETTLING: whether "blocked" should include tasks waiting on a human (agent sessions in awaiting_input, tasks with pending guidance) or only flow-dependency blocks. get_my_attention already distinguishes these. Narrow and correct beats broad and vague.

WHEN DONE: remove the strikethrough styling and the "broken metric" caption from DeltaMetrics, and drop the blocked_metric explanatory object from the delta payload.
