BUILT 2026-07-18 (branch desktop-viewer, V2/desktop/, pushed — NOT merged). Seed questions settled in discussion: (1) use-moment = a live window into the local working state alongside the agent — removes browsing .tasker/ .md files by hand; (2) it earns its place because it inspects WORKING state (pre-flush, live) while the web app inspects CANONICAL state (hub) — different truths, not a duplicate surface; (3) shell = Electron for v0 (machine has Node but no Rust toolchain; Tauri wrap deferred to when a tiny distributable matters — UI is plain HTML/CSS/JS and lifts unchanged); (4) discovery = folder-picker + registry (userData/projects.json); (5) READ-ONLY permanently for v1 — all verbs stay in the coding platform + MCP (State-Layer positioning).

What shipped: editorial-token board (sections→cards, done/total counts), task detail panel (chips, quality-bar rules, safe markdown, ⚖ governance footer hidden), live fs.watch re-render (~250ms debounce) with changed-card flash, .sync.json staleness stamp (device/cursor/synced-Xm-ago), multi-project registry, Open/All filter, search, light/dark themes.

Run: cd V2/desktop && npm install && npm start. Gotcha: launching from inside VS Code requires clearing ELECTRON_RUN_AS_NODE or Electron boots as plain Node.

Follow-ups deliberately NOT in v1: launch-agent-from-card button (deep-link into Claude Code — strongest future wedge, discussed at length), Tauri packaging, hub sync button.
