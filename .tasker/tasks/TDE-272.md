Write a comprehensive developer onboarding guide titled "Getting Started with Tasker's MCP Integration" for the docs site. ALL of these are explicit requirements (the gate checks these exact things):
1. Length: 1400-1800 words.
2. Exactly six H2 sections, in this order: Overview, Prerequisites, Installation, Your first project, Common commands, Troubleshooting.
3. Open EVERY section with a one-sentence summary in italics before any other text.
4. The Installation section must include a fenced ```json code block showing the MCP server config.
5. "Common commands" must list at least 6 example natural-language commands (bulleted).
6. "Troubleshooting" must be a Markdown table with at least 4 data rows (columns: Problem | Fix).
7. Explicitly name the supported clients: Claude Code, Cursor, and Windsurf.
8. Include one concrete worked example: a real command and the result it produces.
9. Do NOT mention or promise features that don't exist — specifically NO mobile app and NO real-time/multiplayer/collaboration claims.
10. End with a "Next steps" line linking to https://smarttasksxdd.netlify.app/docs.
