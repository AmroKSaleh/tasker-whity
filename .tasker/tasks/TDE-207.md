WEAKNESS: operating a 6-step flow took ~12 tool calls (validate_output + submit_validation_result per handoff) — heavy ceremony, especially for deterministic checks.

FIX: collapse the two-phase dance where safe (e.g. one call that returns the rules AND accepts results; auto-run `check` rules as part of validate; allow batching multiple handoffs). Reduce overhead WITHOUT weakening the gate. Watch interaction with #execute-check-rules and #independent-validation.
