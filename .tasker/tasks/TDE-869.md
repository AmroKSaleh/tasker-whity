Code debt found while making the TDE-816 rebuild-or-refine decision on 2026-08-04. Filed separately and deliberately kept OFF the TDE-816 scope, because TDE-816 is on the Phase-1 launch critical path (TDE-790) and refactoring adjacent code while unblocking a launch blocker is how a small change becomes a large one. Do this AFTER TDE-816 ships.

THE DEBT: app/src/pages/FlowsPage.jsx is 660 lines. The `FlowDetail` component is roughly 430 of them (lines 141-575) and interleaves page layout with five unrelated async CRUD mutations written inline: doSaveAsTemplate, doDuplicate, doRename, doDelete, autoAssignShortId/saveShortId. It also carries 13 useState hooks. The project Instruction Set says to consider splitting any component over ~150 lines, so this is roughly 3x the project's own guideline.

WHY IT IS NOT URGENT: none of this code is touched by the Flow redefinition. It is flow *management* (rename/duplicate/delete/template), which the new definition leaves alone — that is precisely the observation that made TDE-816 a refine rather than a rebuild. The debt is real but inert.

WORTH KNOWING: doDuplicate (lines 184-230) contains genuinely non-trivial logic — it remaps old task IDs to new ones to rebuild input edges after duplication. Do not casually rewrite it; move it intact. Same for doDelete's parking-section behavior, which deliberately preserves tasks rather than deleting them.

SUGGESTED SHAPE: extract the mutations into a hook alongside app/src/hooks/useFlows.js (e.g. useFlowMutations), leaving FlowDetail as layout plus handlers. Do not split FlowDetail's layout itself into more components unless it stays over the guideline afterwards.
