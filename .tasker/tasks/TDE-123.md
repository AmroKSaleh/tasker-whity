## CLOSED AS OBSOLETE — 2026-06-30 (decision)
This task was authored in the "Option-1" era (no in-app inference; all AI via MCP). On review, the live V2 app (V2/app) deliberately retains in-app AI: gemini.js + AI project builder (NewProjectModal), Focus-mode why/steps/discuss (FocusOverlay), task-detail discuss/synthesize (TaskDetailPanel), board problem-flags (ProjectBoard, scanProjectFlags), and the Settings AI-provider panel.

DECISION (user, 2026-06-30): KEEP all in-app AI as-is. Do NOT remove. Rationale: in-app AI serves non-MCP web users (indie hackers / solopreneurs in the Foundation audience) for whom it is the ONLY AI; MCP users find it redundant but it costs them nothing. Option-1's premise ("all users are on MCP") doesn't hold for the stated audience.

Known consideration NOT acted on (kept as-is per decision): lib/gemini.js has a built-in Gemini key (VITE_GEMINI_API_KEY) as the default path — if set in prod, the app eats inference cost for the default focus/builder flows. Revisit only if inference cost becomes a real bill; the cheap fix would be BYO-key-only (drop the built-in key) without removing features.

No code changed. section-chat edge function remains deployed (v7) — intentionally left.
