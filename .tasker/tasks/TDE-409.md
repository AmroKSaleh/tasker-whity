Flow step (Local Mode v1 Build — design: V2/docs/local-first-design.md D3/D4/D8). Migration adding the sync spine: projects.local_mode boolean default false; projects.local_revision bigint default 0 (per-project monotonic cursor source); tasks.local_rev bigint (stamped from the project counter by trigger on insert/update so pull can answer "changes since cursor"); local_tombstones table (project_id, task_id, short_id, local_rev, deleted_at, user_id) for delete propagation; local_id_leases table (project_id, device_id, lease_start, lease_end, created_at, user_id) for offline-safe short-ID blocks (D8). Trigger must be no-op-cheap for non-local projects. RLS on new tables consistent with existing per-user policies. Apply to prod via `npx supabase db query --linked --file` (migration tracker is drifted — see KB 82312257); file must be idempotent. Definition of done: introspection query against prod returns all new columns/tables.
