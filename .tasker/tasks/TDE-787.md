TIMING GATE: this is a POST-FOUNDATION (later Phase-1 / early Phase-2) idea, NOT to be built now. Do not pull it forward. It is gated behind foundation satisfaction — see the companion task "Phase-1 exit criteria — define when the foundation is 'satisfied'".

THE THESIS (this is the user's idea, and it is NOT lane-creep — read carefully before dismissing it):
Conventional project-management primitives, when re-expressed THROUGH Tasker's moat (contracts / flows / judge) and the MCP, become something DIFFERENT than they are in Jira/Linear — and could work "amazingly" with what Tasker actually is. The primitive is not the trap; the HUMAN-COORDINATION FRAMING of it is. Run the same primitive through "an agent operates it, a contract gates it, the MCP exposes it, a human owns it" and it can REINFORCE the wedge instead of diluting it.

WHY THIS IS NOT THE "DISCOUNT JIRA" TRAP WE CONCEDED:
Our decisions (state-layer-not-executor; execution-layer; don't-benchmark-vs-Jira/Linear/Asana) reject PM features AS HUMAN-COORDINATION CEREMONY. They do NOT reject the underlying primitives reimagined for an agent-operated, quality-gated, MCP-native world. The distinction is the whole point of this task.

CONCRETE EXAMPLES of the reframe (starting points, not a spec):
- Dependencies: in Jira = human Gantt ceremony; through the MCP = a queryable relationship an agent traverses (this is literally the TDE-556 WIQL-style query-surface steal).
- Sprints/Cycles: in scrum = velocity/burndown ceremony; reframed = a bounded window of GATED AGENT WORK with a durable progress readout (the TDE Cycles-as-container mined idea).
- Views/filters: reframed = a thin human wrapper over the same query engine agents use (one engine, two faces — see the Saved Views mined idea).
- Roadmaps/OKRs/updates: reframed = agent DRAFTS from durable+gated state, human edits & publishes (the "Write with Agent" mined idea, TDE-381).

THE TEST for any candidate primitive (same as the [STEAL]/[CAUTION] mining test): does a SOLO HUMAN BUILDING WITH AI actually need this to run their work, reimagined through moat+MCP — or is it team-coordination ceremony? The former: pursue. The latter: skip.

NEXT STEP (when this task is eventually started): inventory conventional PM primitives, and for each decide (a) skip as ceremony, or (b) reimagine through moat+MCP and how. Output = a shortlist of reimagined primitives worth building, each tied to how it strengthens the wedge.
