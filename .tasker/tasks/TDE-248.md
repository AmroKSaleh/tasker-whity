Depends on the Google OAuth + refresh-token foundation (this group). Only Calendar (events) is integrated today; Google Tasks (the separate to-do feature in the Calendar UI) is not. Bring Google Tasks into Tasker.

Work: add tasks scope (tasks.readonly for one-way, tasks for bidirectional); fetch against tasks.googleapis.com (list task lists → tasks per list).

Open questions (settle before building):
- Landing project policy: dedicated auto-created "Google Tasks" project / user-mapped per task list / always default project.
- Direction: one-way (read-only mirror) or bidirectional (status/text changes push back).
- Conflict resolution if bidirectional.

Lowest priority — single-user workflow; complexity not clearly justified vs. just creating tasks in Tasker directly. Revisit if Google Tasks usage becomes a real constraint or when Tasker goes multi-user. (Merged from former TDE-72 + TDE-224.)
