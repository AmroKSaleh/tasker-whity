From Linear: Cmd+K is the universal verb surface — hundreds of contextual actions, every property has a two-key chord, even UI clicks route through the same command registry; independent reviewers credit keyboard-first design ("design speed makes the path to each interaction short") as much as the sync engine for why devs evangelize it.

Build the INSPECTOR-scale version, not the workspace-scale one: a slim Cmd+K palette with navigation (jump to project/page/task by name or TDE-X) plus roughly a dozen verbs — create task, toggle theme, open Files, open Environments, mark done, set priority. Explicitly not Linear's full action registry: in Tasker the agent is the keyboard; the web app is where the human inspects and nudges.

Fits the existing editorial AppShell (rail navigation stays; Cmd+K is the fast path over it). Bordered-button rule doesn't apply (it's an overlay), but match the Fraunces/editorial identity — no generic dark-glass palette.

## V1 BUILT + DEPLOYED 2026-07-31 — deliberately minimal, per the owner's request to learn the mechanism first

No new UI, no new shortcut. The existing Cmd+K/Ctrl+K search overlay (GlobalSearch.jsx — confirmed live via AppShell on every page; NavigationRail.jsx has its own separate listener but zero importers anywhere, dead code) now matches a short hand-written list of commands by the same query text used for task search.

Six commands to start: **Go to Today / Projects / Flows / Environments / Settings**, plus **Toggle theme** — the one command that's genuinely global with no project context needed. When the box opens empty, all six show immediately (the point of a v1 this small: opening it once shows what it can do). Typing narrows commands and tasks together by substring match, one combined keyboard-navigable list.

Deliberately NOT built yet: a registry/plugin system, or the project-scoped verbs from the original spec (create task, mark done, set priority) — those need to know which project you're on, real complexity this v1 was explicitly asked to skip. Extending is a one-line addition to the `buildCommands` array once the mechanism has actually been used.
