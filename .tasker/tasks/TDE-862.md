https://smarttasksxdd.netlify.app/new returns a completely blank page (0 characters of body text) both logged in and at any viewport.

Cause: app/src/pages/NewTaskPage.jsx exists in the codebase, but app/src/App.jsx has no <Route path="/new"> entry. The component is never mounted. NewTaskPage.jsx is referenced only by itself (it navigates to /dashboard/${slug}?task=${id} on submit).

This matters because TDE-394 ("tasker.new — prefilled task deep link for non-MCP surfaces") is marked DONE. Either it regressed, or the page was built and never wired up. Any tasker.new / /new?title=... deep link currently lands on a blank screen.

Verified 2026-08-02 with the Playwright driver in Z:\Tasker\_check (node sweep.mjs). Screenshot: _check/shots/desktop.new.png.

Related: there is also no catch-all 404 route, which is why the miss renders blank rather than showing anything — filed separately.
