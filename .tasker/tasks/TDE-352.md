GOAL: Rebuild the project view's organizing principle from storage-first (kanban wall as landing) to attention-first ("Front Page" as landing, kanban demoted to "The Stacks", one click deep). Concept mock BLESSED by Ala'a on 2026-07-02 ("I love it").

MOCK: https://claude.ai/code/artifact/6481d427-5aa9-42b6-ae54-7b68e09a0287

THE CONCEPT (editorial, attention-first):
- Masthead: dateline + serif title (Fraunces, already live) + Pulse (%, animated bar, standalone-task fraction) + KB/IS marks.
- HAPPENING NOW = lead slot: indigo lead card for review_verdict.escalated tasks (headline = task text, deck = actual failing critique note, actions: Open / Read critique / Accept as-is). Below: in-flight cards with breathing dots. Zone collapses entirely when empty and NEXT UP takes the lead — the page recomposes around attention.
- NEXT UP: top ~5 from the priority ranker in lib/scoring.js (dormant since Focus mode was disabled) as a numbered ranked list.
- JUST SHIPPED: recent completions with relative timestamps ("while you were away" — an inspector for an agent execution layer must show output, not just queue).
- SECTIONS digest: all sections with micro progress bars, x/y counts, quiet flags (UNTOUCHED / stale) — flags in ink/mute, NOT red (red stays quarantined for systemic failure).
- THE STACKS door: bottom band linking to the full kanban (current board, unchanged mechanics: drag, groups, filters, add-task).

CONSTRAINTS (locked decisions): board/front page = standalone tasks only, zero flow presence, flow tasks out of every count; indigo #4B57D8 reserved for "AI needs you"; single object type; two-halves hierarchy (amplify signal / suppress noise).

DATA: everything is already client-side — review_verdict, statuses, scoring.js ranker, section stats, completed_at. No backend work expected.

IMPLEMENTATION SHAPE: one new component (FrontPage) + a view toggle (Front Page ↔ Stacks) in ProjectBoard; current board becomes the Stacks view unchanged. Open design Qs: which view is default on deep-links; where filters live on the Front Page (likely Stacks-only); Just Shipped window size (last N vs last 48h).

Context: the project view is the most-used page (user experience + external feedback) and the app will be rebuilt around it. A newer, richer visual mock may exist — check the session notes / follow-up artifact before starting.

V2 MOCK (richer, supersedes v1 as the design reference): https://claude.ai/code/artifact/a4ccefa5-db50-4109-8e32-d613c6e4b986 — adds: (1) living masthead "constellation" — a canvas particle field where each mote = one standalone task (grey pending, green done, orange in-flight drifting faster + breathing, indigo escalated), faint pointer parallax, honors prefers-reduced-motion; (2) newspaper lede line under the title ("Since you were last here: 4 shipped, 3 in flight, one needs your judgment"); (3) Pulse % set in the serif; (4) FRONT PAGE ↔ THE STACKS as a real in-masthead view toggle (replaces v1's bottom "stacks door"); (5) lead card critique drill-down — "Read the critique" expands the actual validator FAIL notes inline without leaving the page; (6) The Stacks mocked in the same language (quiet column heads, refined cards, filter pills).
