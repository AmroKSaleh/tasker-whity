From Linear: templates pre-fill team, status, priority, delegated agent, project, labels, estimate, sub-issues, and description scaffolding; a default template auto-applies to new issues; invoked from the composer or shortcuts. (Their form templates with typed required fields = external-requester intake, team-scale — skip.)

Build: named per-project task templates pre-filling section, priority, milestones, and a detail skeleton; list_templates/apply exposed over MCP so AGENTS create consistently-shaped tasks (e.g. a "Bug" template that always lands in Bugs with repro/expected/actual scaffolding); optional default template per project.

Tasker has flow templates but nothing for single tasks. Relates to TDE-342 (task types modify default BEHAVIOR; templates prefill SHAPE — complementary, and a type could reference a template). Wedge angle: consistency of shape is what makes multi-agent state legible — every agent's bug report looks the same.
