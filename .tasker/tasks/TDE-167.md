DONE (2026-06-10). Audited all createable/modifiable entity types and added delete support wherever it was missing.

Delete coverage in the MCP now:
- Projects → delete_project
- Sections → delete_section (NEW)
- Groups → delete_group
- Tasks → delete_task
- Milestones → delete_milestone
- Knowledge Base entries → delete_kb_entry
- Instruction Set entries → delete_is_entry
- GitHub connection → github_disconnect
- Named flows → delete_flow (NEW) — removes the flow record + unlinks tasks (flow_id/flow_step), keeps tasks & edges
- Input edges (I/O deps) → remove_task_input (NEW) — drop one edge by source, or all
- Output contracts → clear_task_output (NEW) — clears the definition-of-done rules, keeps artifact/validation

delete_section refuses on a non-empty section unless delete_tasks:true. All deployed to Supabase and confirmed present in tools/list.

CAVEAT: the four new tools were not runtime-exercised in the session that built them (Claude Code discovers MCP tools at connection, so newly-added tools aren't callable until a fresh session reconnects). They compiled cleanly on deploy and follow the same patterns as the existing, working delete tools. Exercise them in a fresh session to fully confirm.
