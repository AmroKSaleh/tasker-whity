Depends on the Google OAuth + refresh-token foundation (this group). Connect Drive so flows/tasks can store & retrieve files — PDFs, images, Figma exports, binaries GitHub handles poorly. Scope: drive.file.

Work:
- "Connect Google Drive" button → OAuth with drive.file scope (uses the shared foundation).
- On first connect, create a "Tasker" folder in the user's Drive via the Drive API; store folder_id in user_settings; subsequent calls use it as root.
- MCP tools: drive_upload_file (multipart POST), drive_read_file (GET alt=media), drive_list_files (query by parent folder_id).
- Wire store_artifact to optionally upload to Drive (parallel to the existing GitHub commit path).
