From the board UX review (see TDE-346 for full framework). The "amplify signal / suppress noise" half of visual hierarchy. Two concrete changes on the project board:

1. SUPPRESS DEFAULT NOISE: the priority dot + word (e.g. "MEDIUM") is stamped on ~80% of cards because MEDIUM is the default — it drowns the exceptional priorities (RUSH/HIGH) so the eye can't scan for what matters. Fix: hide the priority indicator entirely for the DEFAULT priority (medium). Only non-default priorities (rush/high/low) should render a dot+label. Priority config lives in V2/app/src/components/editorial/atoms.jsx (priority meta object ~line 24); card meta render is in ProjectBoard.jsx (BoardCard, ~line 90-110).

2. LIFT COUNT CONTRAST: section-header counts (x/y) and the pill counts currently use --color-mute-2 (#9A9896) which is ~2.6:1 on the column bg (#F5F3ED) — FAILS WCAG AA (needs 4.5:1). These counts are the at-a-glance health signal, so they must be legible. Bump to --color-mute (#6B6867, ~5:1). The count span is in the Kicker atom (atoms.jsx ~line 11-13, `text-mute-2`).

Verify: build + deploy to Netlify FROM V2/app (not repo root — see deploy memory), user checks on live. Frontend-only, low risk.
