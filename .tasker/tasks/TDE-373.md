Need surfaced 2026-07-06: there's no way to save a whole document/file to a PROJECT (only task-scoped store_artifact, which is really a flow-validation hack). Decision: back it entirely with Google Drive rather than native Supabase storage — this deliberately avoids the "Supabase costs at scale" Foundation risk. Reframed from the TDE-367/371 session where saving the MCP report exposed the gap.

AGREED ARCHITECTURE (user, 2026-07-06):
- Upload from the project view in the web app.
- Document types (md/html/docx/txt/etc.) → uploaded as editable GOOGLE DOCS via Drive convert-on-import.
- All other file types → uploaded AS-IS into the project's Drive folder.
- A button that opens the project's Drive folder (webViewLink) so the user can access everything anytime.

HARD DEPENDENCY: Google Drive must be connected (Settings → Connectors). Feature is unavailable/greyed with a connect prompt otherwise — handle that state explicitly.

WHAT EXISTS TO BUILD ON:
- MCP drive_upload_file(filename, content, target_type: file|doc|sheet, task_id?) already uploads to Tasker/ProjectName/... and supports doc conversion (target_type:'doc' from HTML/Markdown). But it takes TEXT content — binary uploads (images/zip/pdf) need the drive-files edge function extended to accept binary (base64/multipart).
- drive_list_files, drive_read_file (MCP); google-connect/google-callback/drive-files edge functions; Connectors UI.

LIKELY WORK (not a flow — no quality gates):
- Extend the drive-files edge function: accept binary uploads; ensure/create the project's Drive folder; return the folder's webViewLink + id.
- Web: a "Files" area or header button in the project view — upload control (route doc-types → Google Doc, else raw) + "Open Drive folder" button + Drive-not-connected empty state. Optional: lightweight in-app list of the project's files (or rely on the folder link for browsing).

RELATED: TDE-307 (Drive file manager: browse/rename/delete across project folders) — complementary; this task is upload + folder-link, 307 is management. Consider sequencing/merging. Google connector reconsent caveat: KB f7be458a.
