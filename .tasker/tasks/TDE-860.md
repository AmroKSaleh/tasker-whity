The app's landing page (/home, TodayPage) renders only the right-hand calendar sidebar at mobile width. The entire task list — Today's Focus, in-progress tasks, the queue — is invisible.

Measured at 390x844 with Playwright (2026-08-02, against https://smarttasksxdd.netlify.app):
- "Today." heading: width 0px (desktop: 704px)
- "TODAY'S FOCUS" block: width 38px, height 594px (desktop: 704px wide)
- Calendar sidebar: 271px wide — keeps its full fixed width
- document.scrollWidth === clientWidth === 390, so there is NO horizontal scroll to reach the content

So the main column is crushed, not merely pushed off-screen — it is unreachable by any user action. Likely cause: the two-column layout is a flex row where the sidebar has a fixed width and the main column has no min-width and never collapses to a stacked layout at small breakpoints.

Repro: node sweep.mjs (driver lives in Z:\Tasker\_check, untracked via .git/info/exclude). Screenshot: _check/shots/mobile.home.png. Measurement script: _check/diag.mjs.

Probably the same root cause as the board-header mobile bug filed alongside this one — check before fixing separately.

Note: project Foundation says "No mobile app until web is stable and paying" — that's about a native app, not about the web app being broken in a phone browser. Worth a call on whether mobile web is in scope for Phase 1.
