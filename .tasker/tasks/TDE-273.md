FAIR JUDGE EXPERIMENT #3 (hard task, weaker executor). The brief below is the COMPLETE spec given to the executor. The review gate's rules mirror these 15 requirements verbatim — nothing is graded that isn't asked for here.

=== BRIEF (this is what the executor receives) ===

Build a single-file Python module `ttl_lru_cache.py` implementing a class `TTLCache`. Standard library only. It must satisfy ALL of the following requirements.

CORRECTNESS
1. `__init__(self, capacity: int, default_ttl: float)` — `capacity` is the max number of live entries; `default_ttl` is the default time-to-live in seconds.
2. `get(self, key, default=None)` and `put(self, key, value, ttl=None)` must both run in O(1) average time.
3. When the cache is at capacity and a NEW key is inserted, evict the least-recently-used live entry.
4. Per-entry TTL: an entry expires `ttl` seconds after it was inserted/updated, measured with `time.monotonic`; if `ttl` is None, fall back to `default_ttl`.
5. A `get` on an expired entry must remove it and return `default` (treat expired as absent).
6. Both `get` (on a hit) and `put` (on an existing key) must mark that key as most-recently-used.
7. `__len__` returns the number of NON-expired entries; it must not count entries that have expired but not yet been purged.

CONSTRAINTS
8. Thread-safe: concurrent `get` / `put` / `__len__` from multiple threads must never corrupt internal state or raise; guard all shared state with a single `threading.Lock`.
9. Expiry must be LAZY / on-demand only — you may NOT start a background thread, daemon, or timer to expire entries.
10. On an insert that hits capacity, purge any already-expired entries FIRST; only if the cache is still at capacity after purging do you evict the live LRU entry.
11. Python standard library only — no third-party packages.

FORM
12. The class docstring must state the time complexity of `get` and `put`.
13. Provide a `stats(self) -> dict` method returning a dict with integer counts for the keys: `hits`, `misses`, `evictions`, `expirations`.
14. All public methods must have type hints on their parameters and return value.
15. No module-level / global mutable state — all state lives on the instance.

Deliverable: the full contents of `ttl_lru_cache.py`. Output only the file; no prose around it.

=== END BRIEF ===
