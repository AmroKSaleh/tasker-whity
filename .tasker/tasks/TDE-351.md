Re-examine Focus mode (FocusOverlay) from first principles, the same way the project board was rebuilt in the 2026-07 zone-by-zone redesign (Pulse / Now Band / section minimap). Questions to settle: what is Focus mode FOR in an AI-native app where the agent executes most work — is it a human deep-work surface, a steering cockpit for in-flight AI work, or both? How does it relate to the Now Band's resume-in-Focus action and the section focus view (which has its own health sidebar)? Note: as of 2026-07-02 the board excludes flow tasks entirely (boardTasks), and FocusOverlay now receives only standalone tasks — any rethink must respect the flows-live-on-the-Flows-page decision. Relevant code: V2/app/src/components/focus/FocusOverlay.jsx, ProjectBoard.jsx. Next step: audit current Focus mode against real usage, then write a floor-plan-style proposal before implementing.

WHAT FOCUS MODE DOES TODAY (comprehensive, verified against code 2026-07-02 — FocusOverlay.jsx + lib/scoring.js):

CONCEPT: A full-screen "one thing" takeover (fixed inset-0, z-50, own dark ambient vignette + focus theme). It answers "what should I work on right now?" by presenting exactly ONE task, huge, centered, with AI support around it. Opened from the board's Focus button (picks the top-ranked task) or per-task Focus/Resume actions (opens that specific task).

TASK SELECTION & RANKING (lib/scoring.js rankTasks): pinned task = absolute top (score 9999). Otherwise priority points (rush 100 / high 60 / medium 30 / low 10) + due-date urgency (overdue +80, due today +50, within 3 days +20). Each "Skip" divides the score (skip_count decay). EXCLUDED from ranking: done tasks, in_progress tasks (deliberate — "in flight" ≠ "needs picking"), and tasks tagged 'reference'.

NUDGE LAYER (behavioral steering): (1) If opened on a specific task that is NOT the top-ranked one → interstitial "YOUR TOP PRIORITY RIGHT NOW is X — go there instead / continue anyway" (continuing bumps the top task's skip_count). (2) If the same unpinned task has been top-ranked ≥3 days (tracked in localStorage) → "commit and pin it?" prompt. (3) If a pinned task is ≥7 days old → "is this still your top priority?" re-examination prompt (keep / discuss / don't show again, snooze persisted on the task).

MAIN SURFACE per task: giant title (38px) + meta line (priority, due, ★ pinned) · "WHY THIS IS YOUR FOCUS" card — AI-generated one-paragraph rationale · "WHAT TO DO" — AI-generated step plan as an accordion (numbered steps, each with summary + expandable detail, checkable; check-state persisted). Plan is generated on demand ("Generate plan with AI" button; regenerable) — NOT auto-fired on entry, to avoid silent inference cost. All AI calls are the in-app Gemini layer (generateFocusReason / generateFocusSteps / chatAboutTask) grounded in the task, sibling tasks, chat history, and project context.

ACTIONS ROW: Mark as done (closes) · "Skip — show me later" (clears priority + increments skip_count → decays its rank) · "Discuss this task".

DISCUSSION SHEET: bottom sheet (75% height) with a persistent per-task AI chat (messages stored via useTaskDiscussion), "discuss this step N" entry points from the accordion, and an "update plan" action that regenerates reason+steps informed by the conversation.

CHROME: session timer (mm:ss, hideable), Esc closes (sheet first, then overlay), body scroll locked, "All clear" empty state when nothing is actionable.

DATA INPUT (changed 2026-07-02): receives boardTasks only — flow tasks are invisible to Focus mode's ranking, sibling context, and AI grounding.

TENSION TO RESOLVE IN THE RETHINK: this whole surface is built around the HUMAN executing the task (step plans, deep-work timer, motivational "why") — pre-dating the "Tasker is the agent execution layer" strategy where the AI executes most work and the human steers. The Now Band's "Resume in Focus" action also routes in-flight (AI-worked) tasks here, but in_progress tasks are excluded from ranking — the surface's identity is split between "deep-work cockpit for me" and "steering view for work the AI is doing."
