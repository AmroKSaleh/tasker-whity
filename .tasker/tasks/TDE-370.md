Outcome of the TDE-367 strategy discussion (2026-07-06). This exact sentence — "durable, human-shared, quality-gated state that persists across sessions, agents, and people" — is now the canonical description of Tasker's wedge and should be imprinted consistently everywhere Tasker describes itself.

WHY: TDE-367 established that Tasker cannot win as "a better ephemeral scratchpad for the agent" (native platform todos like Claude Code's TodoWrite beat it there on tokens/latency/setup). Its only defensible ground is precisely what native todos structurally CANNOT be: durable across sessions, a human-inspectable shared board, and quality-gated (flows/contracts/validation). The current "AI-native task manager" framing is close but slightly wrong — the wedge is NOT "AI is a first-class user," it's the durable/shared/gated state itself. Full rationale in KB "Positioning: Tasker's wedge is durable, human-shared, quality-gated state (TDE-367)".
