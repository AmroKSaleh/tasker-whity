SHIPPED 2026-06-26. Command-palette task search across all projects.

- New component: V2/app/src/components/search/GlobalSearch.jsx. Opened from the Search rail button OR ⌘/Ctrl-K (listener + state wired in editorial/AppShell.jsx).
- Matches by task TITLE (substring) or SHORT ID — flexible formats: "TDE-52", "tde52", or "52". Ranking: exact short-ID → short-ID partial → title; done tasks sink to bottom (still findable).
- Selecting a result navigates to /dashboard/:slug?task=:id (the board reads ?task= via useTaskPanelState and opens it). Keyboard: ↑/↓ navigate, Enter open, Esc close.
- Fetches lightweight {projects, tasks} from Supabase on each open.
- Deployed to Netlify; committed in 7fd20db.
