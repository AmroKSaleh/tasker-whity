The user must be able to view the result of bootstrap_project (the project Foundation) whenever he wants — both in the web app UI and via MCP.

Context: the Foundation is stored in projects.context (TDE-262). Today it surfaces partially — rendered in the ✦ Foundation panel (UI) and inside get_project (MCP, mixed with sections/tasks), and injected into every get_task as grounding. This task is about giving it a clear, on-demand, dedicated view:
- UI: an always-accessible, readable Foundation view (not just an edit modal) — the user can open and read the full Foundation (core + extended + flexible fields, assumptions/unknowns flagged) anytime.
- MCP: a way to fetch JUST the Foundation on demand (e.g. get_project_foundation), without pulling the whole project dump, so the agent can re-read grounding cheaply.

Goal: the Foundation is a first-class, viewable artifact, not something only seen at creation time or buried in other output.
