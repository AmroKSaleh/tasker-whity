Add a file manager tab/view under Settings → Connectors → Google Drive that lets the user browse all files stored in the Tasker Drive folder hierarchy (Tasker/Project/Flow or standalone/). Operations: rename, delete, open in Drive. This is a read/manage UI — uploads happen from the task detail panel. Only build after the task-level upload UI (TDE-246 Drive implementation) is stable and in use. The file manager should be scoped to the user's connected Drive account and organized by project folder.
