Introduce distinct task types: 'Discussion' and 'Execution'. This changes the default behavior for each type. For example, 'Discussion' tasks might prompt for open questions, feedback, and alignment loops before proceeding, while 'Execution' tasks focus directly on action items, implementation scripts, and output contracts.
