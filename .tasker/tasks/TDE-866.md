/connectors/gmail fails to load its message list. The page shell renders but the data call errors.

Observed 2026-08-02 against https://smarttasksxdd.netlify.app:
- GET https://rzjhmipbamyvpwlkfvxx.supabase.co/functions/v1/gmail-list -> 502
- Reproduced on two independent page loads (1440px and 390px), so not a one-off blip
- Console shows "Failed to load resource: the server responded with a status of 502"
- The page renders only ~459 chars of text (desktop) — effectively an empty panel with no error message shown to the user

502 from a Supabase Edge Function usually means the function threw or failed to boot, rather than a bad request — check the function logs first. Possible causes worth ruling out: an expired Google refresh token surfacing as an unhandled throw (TDE-291 moved Calendar to the refresh-token flow; confirm Gmail is on the same path), or a deploy that left the function in a bad state.

Second issue regardless of cause: the UI swallows the failure silently. A 502 should surface a visible error state, not an empty panel.
