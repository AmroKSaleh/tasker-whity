The current `drive_upload_file` MCP tool only supports creating text-based documents (plain text, Google Docs, Sheets) by accepting a string in the `content` parameter. 

Agents frequently need to upload generated artifacts, source code archives (.zip), or media assets (images/PDFs) to a user's Drive. 

**Proposal:**
Extend the Google Drive MCP integration (or add a new `drive_upload_binary` tool) to accept a local `file_path` parameter. The tool should read the local binary file and upload it directly to the designated Drive folder, supporting arbitrary MIME types.
