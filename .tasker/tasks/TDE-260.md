Read and discuss the KB entry "Case: Brand DNA Drift in Image Prompts — context placement & conformance (2026-06-14)".

It documents a real incident (WCP Article 5 run) where image prompts drifted from the brand guide. The case exposes several Tasker design questions worth a dedicated discussion:
- Task/section-scoped auto-injected Instruction Sets (auto + scoped — the missing sweet spot between project IS and KB).
- Single-entry KB fetch (get_kb_entry) vs. today's all-or-nothing get_knowledge_base.
- Template inheritance / flow-template instantiation so duplicated tasks don't silently miss context.
- Contract validators that grade output against embedded reference material (a brand-compliance gate would have caught the drift).

Goal of the discussion: decide which of these become real roadmap items and how they fit together (context placement + conformance enforcement = Tasker's core value).
