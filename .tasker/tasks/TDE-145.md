═══ VERIFICATION DONE 2026-05-30 (the reality-check I flagged) ═══
GitHub write-back is CONFIRMED UNBUILT. githubFetch() in mcp/index.ts (line 105) is hardcoded GET — no method/body param — and EVERY GitHub call routes through it (also the read-only github.js lib). No POST/PATCH/PUT to GitHub issues exists anywhere. So today the GitHub integration is READ-ONLY IMPORT: github_import_project (issues→Supabase, caps 500) + github_sync_issues (new open issues, additive). The "edit in Tasker → push back to GitHub" loop the founder described is NOT implemented — even the "lens" is really "import + store in Supabase." Local writer.js writes to local .tasker files only (not GitHub). Making lens mode real = build write-back (TDE-148).
