Context updated 2026-08-01:

The original idea was to build a "Write with Agent" button in the React UI (like Plane). However, this is an anti-pattern for Tasker. Tasker's entire wedge is that the AI lives in the user's terminal (Claude Code, Cursor) via MCP.

Building a web UI button that uses browser API keys bypasses the agent the user is actively working with. The terminal IS the UI for drafting.

If we want a formal "Agent Drafts, Human Publishes" system, it should be an MCP capability: an MCP tool like `submit_draft(title, content)` that drops a document into a "Pending Review" inbox in the Web App. The agent calls it, the human edits and publishes in the web app. 

However, this might be over-engineering for Phase 1. Currently, agents already draft from durable state simply by reading via MCP and typing in the terminal. Marking this low priority and moving to backlog.
