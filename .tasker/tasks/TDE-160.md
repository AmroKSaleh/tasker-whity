Feature idea: a button (project-level, and/or session-level) that generates a plain-language summary of everything that was done, what changed, decisions made, problems fixed, and tasks/KB/IS created or modified, over a given window.

Origin: surfaced 2026-05-31. At the end of a long working session in the WQW project (SEO indexing fixes, a WordPress core repair, building an article release flow, plus many task/KB/IS edits), the user asked for a summary of everything we did. That recap is currently produced ad hoc by the AI. A button would make it a first-class, repeatable action.

Suggested behavior:
- Scope options: this session, today, since last summary, or a date range.
- Output: grouped recap (work done, decisions, fixes, items created/edited) with links to the affected tasks/KB/IS entries.
- Optionally append the summary to a project log / report automatically.
- Ties into the broader "flows have persistent context" idea (see the related TDE backlog item on flow-scoped KBs/ISs) and the general project-activity/audit-trail model.

Open questions: does it summarize from the task activity log, from the AI conversation, or both? Where does the output live (modal, exportable, appended to a report)?
