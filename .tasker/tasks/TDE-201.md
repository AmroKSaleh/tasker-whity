WEAKNESS: `kind: check` rules (e.g. `command: npm test exits 0`, `min_length: 500`, `must_include`) are currently just claimed by the agent, not actually run. In the test run I "passed" checks by judgment.

FIX: for check rules, ACTUALLY execute the command / run the count/pattern against the real output, and record the true outcome + raw output as evidence. The agent should only subjectively judge `judgment` rules; `check` rules must be observed, not asserted. Honor the 137 "agent runs it in its env" decision but make the RESULT real. See KB "137 Contract Layer — Design Decisions" → Check execution.
