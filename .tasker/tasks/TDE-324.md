This is specifically when you want to share a task with someone in the team. With the difference being that when you tell the AI that you want to create a task to be relayed, the task gets created not only with its default context saved to it, it will have the "discussion" that the user had with the AI when creating it, removing the need for asking for follow up by the person assigned with the task.

It will make this functionality distinct to the person creating the task by putting [Recording context for the task]

A cool thing to add in a later stage is giving the MCP the ability to access the team members (which will have will defined roles, duties, responsibilities, and capabilities in the database) which will influence the relay works (it can even assign tasks appropriately to the correct team member on its own)
