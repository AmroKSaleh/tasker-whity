Give task cards the ability to list the items attached or connected to them (e.g. linked integration items/artifacts) directly on the card.

Goal: Replace the current method of surfacing these links, which embeds the link inside the task's context/detail box. Instead, the card itself should display its attached/connected items as a first-class element, separate from the free-text context.

Why: Burying integration links in the context box makes them easy to miss and clutters the description. A dedicated "attached items" affordance on the card makes connections visible and scannable, and keeps the context box for actual task detail.

Next step: Define what "attached/connected items" covers (3rd party integration items, linked artifacts, connected tasks), then design the card UI element and migrate existing in-context links to the new structured list.
