The umbrella for the user's 2026-06-19 vision (see KB "Connectors: scoped Tasker-relevant panels, never full app clients").

- Settings → "Connectors" section: lists all providers (GitHub, Google services, Slack, …) with connect/disconnect + status. Generalizes TDE-245's Google-specific OAuth + Settings card into a provider-agnostic registry/UI.
- Connected provider → a sidebar icon opening a SCOPED panel (only the Tasker-relevant slice, in Tasker's UI; never a full app client). Per-app panels hang off this: Gmail TDE-247, Drive TDE-246, Google Tasks TDE-248, Slack TDE-172/286.
- MCP re-exposure layer: connected providers MAY become tools on Tasker's MCP (connect-once-use-everywhere across CC/Cursor/Codex). Apply per-provider — LOW value for Google (agent already has those connectors), HIGH for Slack/agent-absent providers.
- Security: token custodian responsibilities — encrypt at rest, minimal scopes, clean revocation, MCP acts only as the token owner.

Depends on / builds from TDE-245 (Google OAuth foundation). Build order: framework registry + Settings page → per-app scoped panels → MCP re-exposure where it pays.
