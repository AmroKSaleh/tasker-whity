Follow-up to TDE-160 (split out 2026-07-17). TDE-160 shipped v1: a "Day Summary" button on the Today page (components/today/DaySummaryModal.jsx) — MECHANICAL (task-activity-based, no LLM call → free/instant/reproducible, per the user's explicit choice), "today" scope only: tasks completed today, tasks created today, KB entries created today, grouped by project, copy-to-clipboard plain-text export. (TDE-323 "Day Summary Button" was merged into TDE-160.)

THIS TASK = the remaining scope TDE-160 did NOT build:
- Additional scopes: this SESSION, a DATE RANGE, and SINCE LAST SUMMARY (the modal only does "today" today).
- AI-narrated PROSE version — explicitly DEFERRED (not rejected) in TDE-160; build only if the mechanical version proves insufficient. Keep the free/mechanical default; AI-narrated would be an opt-in that costs a call.
- Export beyond copy-to-clipboard (append-to-report / project log).

REUSE: build on DaySummaryModal.jsx's existing grouping logic rather than rebuilding — the "today" path already groups tasks/KB by project; this is mostly parameterizing the window + a "since last summary" cursor.

OPEN QUESTIONS (from TDE-160, still unsettled): does "session" scope summarize from the task activity log, the AI conversation, or both? Where does a "since last summary" cursor live (per-project timestamp)? Where does output beyond the modal go (exportable file / appended report)?

PLACED in the "Session & Cross-Device Continuity" group (Core App) — the recap/continuity theme. Low priority: v1 covers the common daily case; these are enhancements. Related: task-activity/audit-trail model (TDE-374 agent session ledger, now the richer activity source this could draw on).
