THE VISIBLE HOME for Phase-1's launch-blocker list. Phase 1 = make the core hub + MCP great; EXIT = launch. This task is the single place to see "what still blocks launch" until tags (TDE-782) ship and this becomes a `launch-blocker` tag instead.

WHY THIS EXISTS: TDE's sections are organized by TYPE of work (Core App, Flows, Bugs...), which is an orthogonal axis to PHASE (is-this-a-launch-blocker). You can't encode both axes in one flat section list without one destroying the other. So launch-blocker status is expressed as a LABEL, not a section: for now, this tracker (a pinned list by ID); later, the TDE-782 tag. Do NOT create a "Phase 1" section and rip tasks out of their type homes — that loses the type grouping used daily.

HOW TO USE: as the capability checklist is drafted (TDE-789), list the blocking task IDs below with a one-line why. A task is a launch-blocker if the core hub+MCP would be embarrassing / incomplete to show the world without it — NOT merely "would be nice." Keep this list SHORT; most of the ~80 open tasks are not blockers.
