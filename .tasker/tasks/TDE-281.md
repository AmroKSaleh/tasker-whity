Concept discussed 2026-06-18 (Alaa).

**Problem:** Tasker flows currently assume AGENT execution — run_flow self-sequences through tasks, the agent does the work, stores artifacts, validates via subagents. But many real flows are executed by the HUMAN (or an external party), not the agent. Proven live this session: the WCC newsletter build sequence (WCC-F3) was almost entirely user-executed (create Brevo account, upload PDF, hand DNS records to the web admin, paste the email template). There is no native "walk the human through this, one step at a time" mode, so the agent faked it — manually calling get_flow_order / get_task and re-finding the place on every resume. That friction is the missing feature.

**What it is NOT:**
- NOT a dumb sequential checklist. Tasker literally began as an HTML checklist the agent ticked off; flows must stay smarter than that.
- NOT a new flow CATEGORY. It is a different METHOD OF OPERATION (an execution mode) that any flow can use.

**Proposal:**
1. **`executor` attribute per task** — agent / user / external. Lets a single flow be hybrid (some steps the agent runs, some the user does, some wait on an external party like a web admin). WCC-F3 was exactly this mix.
2. **A "guide mode"** that walks the human steps one at a time: a persistent "you are here" cursor, next/done progression, resumable across sessions. run_flow keeps handling agent steps; guide mode pauses on external steps.

**The differentiator (core requirement):** it must be an AI-GUIDED human flow, not a static wizard. Per step the agent explains the step, answers "why," adapts when the user hits a snag (e.g. the Brevo DNS-records hunt), and verifies the user's output before advancing.

**Needs:**
- Persistent current-step cursor (resumable) — we lost our place repeatedly this session.
- Per-step human-facing guidance, distinct from the agent-facing prompt.
- Completion with evidence (link/note), same pattern as Asset Wishlist milestones (done only when a link is provided).
- Agent role = coach + verifier, not executor, for user steps.

**Origin/evidence:** the entire WCC-F3 run on 2026-06-18.
