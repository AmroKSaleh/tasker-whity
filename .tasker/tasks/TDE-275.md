Add an MCP tool to rename an existing section (e.g. update_section with a name field, or rename_section). Currently there is no way to rename a section via MCP — create_section, delete_section, and list_sections exist, but no rename. Workaround today is destructive and clumsy: create a new section, move every task over via update_task, then delete the old empty section. Surfaced 2026-06-17 while reorganizing WCC sections.
