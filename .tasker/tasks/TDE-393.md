From Linear: the Agent Interaction Guidelines (/developers/aig) are a published, versioned behavioral contract — six principles (disclose you're an agent; inhabit the platform natively; instant feedback; legible internal state; respect disengagement; "an agent cannot be held accountable" — humans keep responsibility via delegation). Published as a living document, community input invited. It costs them nothing and buys enormous positioning credibility.

Build: Tasker already HAS this content — the __init_tasker_session directive playbook (task lifecycle, flow rules, validation behavior, organic lifecycle). Version it and publish it as a named public doc on /docs: "How agents behave in Tasker" — write activities not vibes, the human holds the gate, honor stop signals, converge on existing tasks (no dupes), completion means verified.

Same artifact, both directions: instructions TO visiting agents (what init already sends) and a public contract humans can read to trust the system. Cross-ref TDE-330 (playbook additions) and the Tasker Method essays task — AIG is the technical annex to the Method.
