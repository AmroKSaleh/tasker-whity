## Design Context

**Section Focus Mental Model:**
- Project = the complete machine (all moving parts in concert)
- Sections = gearboxes (self-contained functional units that work together)
- Groups = how you organize gears within a gearbox (logical groupings of related tasks)
- Tasks = individual gears (atomic units of work)

When in section focus mode, user zooms into one gearbox to understand its state and work on getting its gears aligned.

## Current Sidebar Behavior
The AI sidebar currently displays raw data:
- Task counts (Done/In Progress/Pending)
- Groups list with task counts
- Recent 5 tasks
- Chat interface for user to ask questions

**Problem:** User must know there's something to investigate. How does the sidebar surface problems the user doesn't know to ask about?

## Required Capabilities
The section focus screen should proactively tell the user:
1. **Something is wrong that needs removing** (e.g., duplicate tasks, obsolete groups)
2. **Something is missing that needs adding** (e.g., missing prerequisites, gap in coverage)
3. **Something is lacking that needs modification** (e.g., imbalanced workload, stale tasks)

All insights depend on AI analysis and user discussion feedback.

## Proposed Solutions

### Option 1: Auto-analysis on Focus
When entering focus mode, AI runs quick diagnostic → surfaces 1-2 key findings as cards/chips
Example: "⚠️ 3 tasks blocked by dependencies" or "Group X is 40% of workload"
Pros: Proactive, forces visibility
Cons: May feel like noise if not relevant

### Option 2: Visual Health Indicators
Context box shows metrics with color coding
- Pending count: orange if > 5
- Group workload: red if > 50% of section total
- Stale tasks: flag if pending > N days
Pros: Always visible, glanceable
Cons: Requires clear visual language

### Option 3: Structured Summary (Recommended)
Instead of raw counts, show structured breakdown:
- **Balance**: Group A (5 tasks) | Group B (3 tasks) | Group C (7 tasks) — visual imbalance flags itself
- **Blockers**: "2 tasks waiting on TDE-45"
- **Stale**: "TDE-12 pending for 5 days"
Pros: Provides context naturally
Cons: Needs careful design to avoid clutter

### Option 4: Hybrid (Most Promising)
Combine structured summary + auto-analysis
1. When focusing on section: immediately see gearbox state visually
2. AI diagnosis shows top 1-2 problems below the context
3. User can ask deeper questions in chat

## Next Steps
1. Decide which approach fits the user's workflow
2. Design the visual layout for problem surfacing
3. Implement AI diagnostic prompt that analyzes section state
4. Test with real section data to refine what counts as a "problem"
