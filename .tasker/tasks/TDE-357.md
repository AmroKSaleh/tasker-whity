Part of the Environments series (parent design TDE-308; hierarchy Tasker → Environments → Projects). Depends on 1/5 (TDE-354, DB: environments table + projects.environment_id) and 2/5 (TDE-355, MCP scoping).

GOAL: implement the deliberate EXCEPTION to exclusive Environment switching. Exclusive switching (locked in TDE-308) hides other Environments' projects and board when you switch — but Today and Focus must deliberately span ALL Environments so the user is never blinded to a task due today in another Environment (that would turn switching into a way to forget things). Each Today/Focus item carries a compact Environment badge (name + color) so the cross-env mix stays legible.

KEY DECISIONS (from TDE-308):
- Today/Focus = cross-environment, NOT scoped to the active Environment (opposite of the board, which 3/5 scopes).
- Per-item Environment badge derived from the item's project → environment_id.

NEXT STEP: in the Today page + Focus surfaces, do NOT filter by active environment; join each task → project → environment and render a small per-item badge. Primary file: V2/app/src/pages/TodayPage.jsx (+ any Focus surface). Reuse the environment color/name once the DB + MCP parts land.

OPEN: exact badge visual (chip vs dot+label) — settle against the editorial atoms during build.
