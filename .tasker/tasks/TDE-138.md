Currently, when a task has an unmet input dependency, the MCP returns a plain text warning. We want it to show as an interactive dialog popup in Claude Code where the user can choose to either complete the dependency or proceed anyway. This requires figuring out how to trigger Claude Code's dialog system from MCP tool responses. The questionnaire format works for __init_tasker_session but doesn't automatically trigger for other tools.
