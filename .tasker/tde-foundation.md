# Tasker Development — Foundation

_The project's north star. Read once at session start. Read-only snapshot._

- Goal: Ship Tasker as a B2C SaaS product targeting developers, indie hackers, and solopreneurs — with the Claude Code MCP integration as the core GTM wedge
- Why (intent): The MCP integration is a genuine differentiator. No other task app lives inside the developer's AI workflow. The window to own this positioning is now, before larger tools copy it.
- Scope (in / out): Web app (React/Vite/Supabase), hosted MCP server, platform integrations (CC, Cursor, Windsurf), freemium monetization. No mobile app until web is stable and paying.
- Success looks like: App is live, freemium model is enforced, CC integration is documented and discoverable, first 10 paying users
- Risks: MCP becomes commoditized by larger tools, Supabase costs at scale, scope creep on features before monetization is in place
